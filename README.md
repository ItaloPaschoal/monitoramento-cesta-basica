# 🛒 Monitoramento de Preços da Cesta Básica

Projeto desenvolvido para a experiência prática da disciplina **Algoritmo e Pensamento Computacional**.

## 📌 Sobre o Projeto
O sistema visa monitorar a variação percentual de preços de produtos da cesta básica entre dois meses consecutivos, auxiliando órgãos de defesa do consumidor na identificação autônoma de reajustes abusivos.

## ⚙️ Funcionalidades
- Entrada de dados para 3 produtos da cesta básica.
- Cálculo preciso da variação percentual de preço.
- Classificação automática da situação do produto:
  - **AUMENTO ABUSIVO**: Variação superior a `10%`.
  - **AUMENTO**: Variação positiva (entre `0%` e `10%`).
  - **QUEDA**: Variação negativa (`< 0%`).
  - **ESTÁVEL**: Sem alteração de preço (`0%`).
- Exibição de relatório detalhado por item.

## 🛠️ Tecnologias Utilizadas
- **VisuAlg / VisuAlg Web**: Interpretador de Pseudocódigo (Portugol).
- **Lógica de Programação**: Variáveis reais/caractere, laços de repetição (`para`) e estruturas condicionais encadeadas (`se / senao`).
